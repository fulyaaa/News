# News App 📱

A news application built with Swift and UIKit following MVVM architecture.

## Features
- Browse top headlines from NewsAPI
- Search news articles
- View article details
- Share articles via native share sheet
- Light/Dark mode support
- Localization (English & Turkish)
- Notification permission support

## Architecture
- MVVM + Protocol
- URLSession for networking
- Kingfisher for image loading
